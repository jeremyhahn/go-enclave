### Added

- **confidential-vm**: A new module, backends/confidentialvm, gives a program in an SEV-SNP or TDX guest on Linux amd64 a standalone Attester, no backend: NewAttester reads the configfs-tsm provider and Attest returns the guest's report as Evidence of format "sev-snp-report" or the TD quote as "tdx-quote", over the nonce zero-padded to 64 bytes, from an entry of its own that it removes on every path. A refused step is a *TSMReportError naming it and matching ErrTSMReportUnavailable (Cause ErrTSMReportConflict when another writer moved generation), a bad nonce is enclave.ErrInvalidNonce, off linux/amd64 the constructor refuses, and nothing registers at import.
- **confidential-vm**: In an SEV-SNP guest, backends/confidentialvm's NewKeyProtector returns an enclave.KeyProtector for ModePerOperation that seals each key with AES-256-GCM under a key the firmware derives through /dev/sev-guest from the chip's VCEK and the guest's policy, launch measurement and the committed TCB version recorded at construction, held in locked memory for one call and wiped. A blob opens only in a guest with the same binding at a TCB not below its own and otherwise matches enclave.ErrSealedAuthentication, while a refused derivation, in a TDX guest too, is a *DerivedKeyError matching ErrDerivedKeyUnavailable.
- **confidential-vm**: A test kit for backends/confidentialvm on real SEV hardware: scripts/amdsev-guest.sh launches an SNP, SEV-ES or plain KVM guest from a pinned local OVMF build and a direct-boot kernel with no network device and exits with the guest test binary's status (--dry-run prints the QEMU command), and scripts/amdsev-host-scan.sh scans a QEMU process's readable memory on the host for a needle the guest holds, exiting 2 when any readable mapping cannot be read. Neither downloads anything.

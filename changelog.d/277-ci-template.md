### Changed

- CI follows ci-template v1.31 and nightly-template v1.9: the lint steps run in their own `Lint` job beside the build, with `make gosec` on every pull request and a private-pattern releasability step; `Lint Gates` is path-scoped; every job has a timeout; a schedule guard refuses a manual full-tier run off `main`; and a nightly `Lint sweeps` job runs `make lint-sweeps` once the Makefile defines that target (go-enclave defines none yet, so the job prints that there is nothing to run and builds no image). New `make docker-build-toolchain` builds the toolchain image alone. go-enclave keeps its hosted runners, its image build without forge credentials, and its swtpm and OP-TEE jobs (#277). Nothing changes for Go callers.

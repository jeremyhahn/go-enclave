### Added

- **confiner-sev-snp**: A new module, backends/amdsev, whose New(a) returns an enclave.Backend named "sev-snp" only inside an AMD SEV-SNP guest on Linux amd64: an enclave.Confiner whose ConfinesProcess is true and an enclave.Importer whose handles are locked-memory enclaves admitted through the Allocator a. On the host, in a plain KVM guest and in an SEV or SEV-ES guest without SNP, New returns a *GuestError naming the refused step and matching ErrSNPGuestUnavailable, and claims nothing; off linux/amd64 it returns ErrSNPGuestUnavailable. Nothing registers at import.
- **confiner-sev-snp**: A test kit for backends/amdsev on real SEV hardware: scripts/amd-sev-snp/amdsev-guest.sh launches an SNP, SEV-ES or plain KVM guest from a pinned local OVMF build and a direct-boot kernel with no network device and exits with the guest test binary's status (--dry-run prints the QEMU command), and scripts/amd-sev-snp/amdsev-host-scan.sh scans a QEMU process's readable memory on the host for a needle the guest holds, exiting 2 when any readable mapping cannot be read. Neither downloads anything.

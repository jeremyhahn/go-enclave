### Added

- **`intel-tdx` attestation: `Backend.Attest(ctx, nonce)`** (#199). Each call makes its own configfs-tsm report directory, writes the nonce zero-padded to the 64-byte REPORTDATA (the backend writes all 64 bytes; a nonce and the same nonce with trailing zeros give one REPORTDATA, so a relying party that cares sends 64 bytes), checks that `provider` reads `tdx_guest` and that `generation` counts only its own write (`ErrTSMReportConflict` otherwise), and returns `Evidence{Format: "tdx_guest", Data: <the TD quote as outblob returned it>}`; the format name is exported as `EvidenceFormat`. A nonce of 0 or more than 64 bytes is `enclave.ErrInvalidNonce` before any request. Calls on one backend are serialized. Off a TD it refuses with a `*TSMReportError` naming the step, and off linux/amd64 the stub refuses with `*GuestDeviceError` ([design](docs/backends/intel-tdx.md#attestation), Q4 and Q5).

# Plan: known-answer vectors that pin blob contract v1 (#334)

Part of epic #264 (keyprotector providers).

## Objective

`docs/sealing/engineering.md` "Blob contract v1" is normative: changing any
byte is a format change. Pin those bytes with known-answer vectors that a
second implementer (the OP-TEE TA) can use, checked two ways: against a
reference encoder written from the document with the standard library only,
and against the package's own unwrap and open paths.

## Slices

1. **Vectors and test (test commit).** `contract_v1_test.go`, internal
   package, with:
   - a reference encoder from the documented layout (crypto/aes,
     crypto/cipher, crypto/hkdf, encoding/binary), with its own copies of the
     documented constants;
   - `testdata/contract-v1/*.json`: fixed root key, salt, keys, nonces,
     plaintext and expected bytes for
     - the SoftwareProvider blob (kind 3, generation 0, 66 bytes) and a
       sealed value under it, envelope versions 1 and 2;
     - a ModeRootKey KEK blob (kind 2) under the HKDF wrapping key, a DEK
       blob (kind 1) under that KEK generation, and a sealed value with the
       blob as AAD, envelope versions 1 and 2;
     - refusals: version 2 header, wrong kind, flipped tag byte, short blob,
       each `ErrSealedAuthentication`;
   - `TestContractV1_ReferenceEncoder`: rebuilds every vector byte for byte;
   - `TestContractV1_PackageOpens`: opens every vector through
     `softwareProvider.Unprotect` and a `Sealer`'s `Open` (SoftwareProvider),
     `deriveWrappingKey` and `unprotectRootKey` (ModeRootKey, KEK generation
     retired so the KEK blob is unwrapped too), `sealedAAD` and
     `openWithKeyInto`; refusals return `ErrSealedAuthentication`;
   - `-update-vectors` (off by default) rewrites the files from the
     reference encoder.
   - FIPS 140-only mode refuses a GCM with a caller's nonce, so there the
     reference side opens each vector (`NewGCMWithRandomNonce`) instead of
     rebuilding it; the package-path half runs in both modes.
2. **Seam (only if needed).** None expected: the vectors are built by the
   reference encoder, and the package only opens them, so no fixed nonce is
   injected into production code.
3. **Docs.** One sentence and link in "Blob contract v1" and "Test strategy";
   changelog fragment `changelog.d/334-contract-vectors.md`.

## Out of scope

- Key-handle (`WithBackend` `AEAD`) blob layouts: unpinned by the document.
- Generic provider blobs and any serialized envelope form.
- Any production behavior or exported API change; nothing under `backends/`.

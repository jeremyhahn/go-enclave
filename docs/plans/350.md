# Plan: integration runner shell tests and a strict floor (#350)

## Objective

`build/docker/devcontainer/run-integration-tests.sh` runs one integration
suite with the library instrumented for coverage and gates it through
`scripts/coverage-gate.sh`. It has no test, and its floor check
(`*[!0-9.]*`) accepts `1.2.3` and `.`. Add a POSIX sh test that drives the
script with a stub `go` on PATH and the real coverage gate, then make the
floor check accept only `N` or `N.N...`.

## Slices, in order

1. Test commit: `build/docker/devcontainer/run-integration-tests_test.sh`,
   run from a scratch tree holding `test/integration/<pkg>`, a copy of the
   runner and the real `scripts/coverage-gate.sh` and `scripts/lib.sh`. The
   stub `go` answers `test`, `tool covdata textfmt` and `tool cover -func`
   from fixture profiles. Cases:
   - usage refusals exit 2 with their message: no package, a bad package
     character, a missing, empty or malformed floor, a missing COVERPKG or
     TESTFLAGS, a missing suite directory; no `go` call on a refusal;
   - `go test` failing and `covdata` failing each fail the run;
   - the `go test` call carries the flags, `-cover`, `-coverpkg`, the suite
     and the same GOCOVERDIR in its environment and `-test.gocoverdir`;
   - a profile at the floor passes; one statement under fails and prints
     `Least-covered functions`; a cover package absent from the profile
     fails;
   - PROFILE_OUT as a path copies the profile; `-` prints it between the
     BEGIN/END markers;
   - the covdata directory and the profile are removed on every exit.
   Known defects print `SKIP defect: ...` until fixed. `make check-it-runner`
   runs the test and `make lint-gates` runs that target.
2. Fix commit: a strict floor check (`N` or `N.N...`), so `1.2.3`, `.`,
   `1.` and `.5` exit 2 before `go test` runs; the SKIP cases turn on.
3. Fix commit: the `${VAR:?}` refusals exit with the shell's own status
   (2 in dash, 1 in bash as sh); each refusal now exits 2 explicitly,
   and the test runs the refusals under every available sh (dash, bash).
4. Changelog fragment `changelog.d/350-it-runner-tests.md`.

## Out of scope

- The Makefile side of `make integration-test-<pkg>` and
  `scripts/integration-test.sh`.
- Signal handling (an EXIT trap under SIGINT/SIGTERM).
- Changing the coverage gate itself.

# Plan: runnable sealing examples (#340)

## Objective

The root package has no `Example` for sealing, so pkg.go.dev shows no
runnable sealing usage and `go test` compiles none. Add
`example_sealing_test.go` (package `enclave_test`) with four examples that
print only non-secret facts and destroy every handle they make.

## Slices, in order

1. Examples (test commit). `example_sealing_test.go`:
   - `ExampleNewSealed`: seal a credential (its slice is wiped), `Open`,
     read the length in the `WithBytes` borrow window, destroy both, and
     show that an open after `Destroy` matches `ErrEnclaveDestroyed`.
   - `ExampleNewSealedFrom`: seal from an open memory enclave; the source
     stays alive and intact.
   - `ExampleSealed_OpenIn`: open into `DefaultBackend()`; the handle has
     `ByteAccess` and the expected size.
   - `ExampleNewSealer`: `WithKeyProtector(enclave.NewSoftwareProvider())`
     gives `ModePerOperation`; seal and open through it, then destroy the
     sealer and show `ErrSealerDestroyed`.
   Each has an `// Output:` block, so `go test -run Example ./` runs it,
   in the default and the FIPS 140-3 only modes.
2. A doc-comment fix, only if an example shows one disagreeing with
   behaviour (example commit first).
3. `docs/sealing/user.md`: align a code fence only where it shows the
   same calls as an example and differs from it.
4. Changelog fragment `changelog.d/340-sealing-examples.md` (`### Added`).

## Out of scope

- `example_test.go` and examples for the memory enclave, allocator,
  detection and sweep (another issue).
- Any production code change beyond a doc comment.

# Plan: the TCG TPM 2.0 standards the TPM provider implements (#335)

Epic: keyprotector-providers (#264). Slice: standards first for the TPM
provider in `backends/tpm`.

## Objective

`docs/reference/README.md` copies and indexes each standard the code
implements. The TPM provider implements TCG TPM 2.0 (it marshals
`TPM2_Create` and `TPM2_Unseal` itself and uses `TPM2_CreatePrimary`,
`TPM2_Load`, `TPM2_StartAuthSession` and `TPM2_FlushContext`) and builds its
parent from the TCG storage-key (SRK) template. Copy each document at the one
revision the code follows, or, where its licence forbids a copy, record its
title, revision, canonical URL and the reason.

## Revision

`backends/tpm/go.mod` requires `github.com/google/go-tpm` v0.9.8. Its `tpm2`
package defines no command code after `TPM_CC_ACT_SetTimeout` (0x198) and
none of those revision 1.83 adds, so the provider follows TPM 2.0 Library
revision 1.59.

# Plan: epic #264, keyprotector-providers — remove the hardware providers

> **Status: REFERENCE** · Scope: go-enclave · Last verified: 2026-11-21

## Objective

The SPEC's "Key-operation API removal" moves the hardware `KeyProtector`
providers to go-xkms. This row removes both from go-enclave: the TPM
provider (`backends/tpm`, a nested module) and the TrustZone provider
(`(*armtrustzone.Backend).KeyProtector`). The root `KeyProtector` seam,
`SoftwareProvider` and `providertest` stay; so does the arm-trustzone
backend (Connect, Connector, Random, backendtest conformance). With both
providers gone the row is shipped.

## Slices, in order

1. **Plan** (this file).
2. **Tests first.** Drop the TPM cases from `build/ci/buildgates`
   (`swtpm_install_test.go`, the `tpm` change-filter and tier cases) and the
   `swtpm-fixture` cases from `scripts/project-scripts_test.sh`. Only tests
   of removed code go.
3. **Remove the code.** `git rm -r backends/tpm`; delete
   `backends/armtrustzone/protector*.go` and the tests that serve only the
   provider; drop `taCmdSeal`/`taCmdUnseal`, `keyProtectorLabel`, the seal
   size bounds and the SEAL/UNSEAL fakes; `go mod tidy`. Remove
   `scripts/swtpm-fixture.sh`, the Makefile `integration-test-tpm` target
   and `SWTPM_*` variables, `backends/tpm` from `BACKEND_MODULES`, the CI
   `tpm-swtpm` job and its `changes` output and CI Gate check.
   Tests: `make test-enclave`, `go test -race ./...` in
   `backends/armtrustzone`, `make lint-gates`.
4. **Docs.** SPEC row shipped, ROADMAP Complete, Upgrading migration in
   `docs/README.md`, a BREAKING changelog fragment, the TCG TPM 2.0
   reference copies and index rows removed (no code implements them),
   `hardware-providers.md` cut to a removal note, every other page that
   names the providers brought in line with the code.

## Out of scope

- `Attester` and `Evidence`: their removal is a later row.
- Any provider code in go-xkms.
- `docs/plans/*.md` and `docs/plan-349.md` (historical plans).

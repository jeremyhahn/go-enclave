# Plan: SPEC row provider-conformance (#452)

## Objective

`providertest.TestProvider(ctx, cfg)` checks that a provider retains nothing,
refuses tampered and forged blobs, honors its context and implements only the
modes it claims; it fails closed where it cannot measure. This row folds the
open per-item PRs into one branch and one PR, keeps each one's intent, and
leaves docs/SPEC.md marking the row shipped.

## Slices, in order

1. **#331 / PR #360, memscan signal count.** Merge its head with `--no-ff`.
   Tests: `internal/memscan/plant_linux_test.go` counts a signal only inside
   a needle comparison; a negative control whose searches only clear their
   buffer must count none. Its two numbered changelog fragments are a
   test-only change and are dropped (test changes get no fragment).
2. **#366 / PR #379, memscan fuzz.** Merge its head. Tests:
   `memscan_fuzz_test.go` and `memscan_fuzz_linux_test.go` fuzz the maps-line
   parser and the maps walk; the `memscan.go` fix rides with them.
3. **#368 / PR #381, providertest error contract.** Merge its head (largely
   already carried by #379). Test: `errors_contract_test.go` holds every
   exported error type to the `errors.Is` / `Unwrap` contract; the
   `FindingsError` empty-findings message fix rides with it.
4. **#348 / PRs #390 and #428, residue matrix.** Merge #390, then #428
   (which already contains #390). Tests: `residue_matrix_linux_test.go` and
   `residue_leaks_linux_test.go`, one provider per way of keeping a key; the
   half-key sweep fix in `residue.go`. Numbered changelog fragments fold into
   `changelog.d/provider-conformance.md`; the plan files `docs/plans/331.md`
   and `docs/plans/348.md` fold into this plan and are removed.

Departures, found by the row's own runs under `-race -cpu=1,2,8`:

- After #360, the parked-thread control counted signals (the signal wakes
  the parked thread). `readParent` now counts a signal only once its compare
  window has closed; the existing controls are the test.
- After #390/#428, the residue sweep runs three times per check and hit EIO
  on a mapping the runtime unmapped mid-sweep (`TestAForgeThatFailsIsReported`).
  `memscan.Find` lists the mappings again, up to three times; new `sweep`
  tests in `memscan_linux_test.go` prove the retry and the fail-closed bound.
- PR #379 also carries the `backends/tpm` error-contract work (#371), which
  main lacks; the merge keeps it whole and `make test-backends` passes.

5. **Close-out.** docs/SPEC.md keeps the row `shipped`; the
   provider-conformance docs carry a fresh `Last verified:` date.

Each slice runs `make test-memscan` or `make test-providertest` (and
`make test-provider-conformance`) before its merge commit lands.

## Out of scope

- New provider checks beyond the folded items.
- Backend modules (`backends/tpm`, `backends/armtrustzone`).
- Integration tests needing Docker: CI runs them.

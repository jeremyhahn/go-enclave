# Plan: imx-edgelock-enclave backend (#195)

## Objective

Build the i.MX EdgeLock Enclave backend that
[docs/backends/imx-edgelock-enclave.md](../backends/imx-edgelock-enclave.md)
proposes: a nested Go module `backends/imxele`, laid out like
`backends/armtrustzone`, depending on go-enclave and `golang.org/x/sys` only,
registering nothing at import. It reaches trusted-imx95's trusted application
over the Linux TEE subsystem and passes `backendtest` on the FRDM-IMX95-PRO.

## Slices

1. **Module, typed errors, probe, refusal path** (this slice).
   - `backends/imxele/go.mod`, doc, the typed errors of "Failure modes"
     (`TEEDeviceError`, `TEESessionError`, `ABIVersionError`,
     `TEECommandError` and their sentinels).
   - `Probe`: check ctx, open `/dev/tee0`, `TEE_IOC_VERSION` (OP-TEE, GP
     client), close. The session and version-command steps refuse with
     `ErrTEESessionUnavailable` until trusted-imx95 publishes its ABI.
   - `Connect` runs the same check; `Name`, `Rank` (above arm-trustzone, Q3).
   - Stub off Linux: `TEEDeviceError{Op: "platform"}`, no cause.
   - Tests: the version parser on a fixed 12-byte buffer; the probe and
     constructor refuse on a host without `/dev/tee0`, naming the step; the
     stub test off Linux; cross builds linux/arm64, darwin/amd64.
   - Makefile `BACKEND_MODULES` gains `backends/imxele`.
2. **Session and version command**, once trusted-imx95 publishes the TA UUID
   and command ABI: `TEE_IOC_OPEN_SESSION` with `TEE_IOCTL_LOGIN_USER`, the
   version command, `ABIVersionError`. The TEE client is shared with
   arm-trustzone; where it lives is decided in that slice.
3. **Keys**: native `GenerateAEAD`, `GenerateSigner`, `Random`; handles
   (`AEAD`, `crypto.Signer`), `Destroy`; `TEECommandError` with timeout.
4. **Import, Sweep, Attest** (Q5, Q6).
5. **Conformance on the board**: `backendtest`, the integration target.

## Out of scope

- Any simulator, emulator or mock device (owner ruling); no fake device tree.
- Changes to the root module beyond the Makefile line.
- Appraising evidence or the device lifecycle (Q7: the probe does not refuse
  an open lifecycle).

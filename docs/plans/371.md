# Plan: one contract for every tpm error type (#371)

## Objective

`backends/tpm/errors.go` declares the module's error types and `Err...`
sentinels. Hold every one of them to one contract in a single table test,
and fail the build when a new exported error type or sentinel lands without
a row.

## Contract (per row)

- `Error()` on the zero value and on a populated value: no panic, non-empty,
  carries the `tpm: ` package prefix.
- `errors.Is` matches the row's sentinels and no other package sentinel.
- `errors.As` finds the type through `fmt.Errorf("%w")` and `errors.Join`.
- `Unwrap` exposes the cause; a nil cause unwraps to nil.
- A marker byte string in any key- or blob-adjacent input never appears in
  the message; no exported error type carries a byte-slice field.

## Slices

1. Test commit: `backends/tpm/errors_contract_test.go` with a row per error
   type (`PlatformError`, `DeviceError`, `CommandError`, `KeySizeError`,
   `authError`) and per sentinel, plus a `go/parser` completeness check over
   the module's non-test files. Rows that expose a defect carry the correct
   expectation and `t.Skip("defect: ...")`.
2. One fix commit per defect in `errors.go`, dropping its skip. Known from
   reading: `DeviceError.Error` and `CommandError.Error` dereference a nil
   `Err` on the zero value.
3. Changelog fragment `changelog.d/371-tpm-errors-contract.md`, then a
   simplify pass over the new test code.

## Out of scope

- `blob.go` and the transport files (other lanes fuzz them).
- Error types of other modules.

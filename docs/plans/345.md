# Plan: one contract for every exported error type (#345)

## Objective

Hold every exported error type of the root package to one contract, in one
table test, with a completeness check that fails when a type or sentinel is
added without a row.

## Contract (per row)

- `Error()` on the zero value and on a populated value: no panic, non-empty,
  starts with the package prefix `enclave: `.
- `errors.Is` matches the row's sentinels and no other exported sentinel of
  the package (checked against the full sentinel list), directly and through
  `%w` one and two levels deep.
- `errors.As` recovers the same value through `%w` one and two levels deep and
  through `errors.Join`.
- `Unwrap`: single-cause types return the cause, and nil on the zero value;
  multi-cause types (`Unwrap() []error`) include the cause and return nothing
  on the zero value; types without a cause implement neither.
- Marker: a raw byte string with non-printable bytes placed in every string
  field (names a caller supplies) never appears verbatim in the message; a type
  that gains a string field without a marker constructor fails the table.

## Completeness check

Parse the package's non-test files with `go/parser`; collect exported types
named `...Error` and exported `Err...` variables; fail on any without a row
in the table or the sentinel list, and on any row naming nothing declared.

## Slices, in order

1. Test commit: `errors_contract_test.go`, rows as the code behaves today; a
   row that exposes a defect carries `t.Skip("defect: ...")`.
2. One fix commit per defect, dropping its Skip.
3. Changelog fragment `changelog.d/345-errors-contract.md`.

## Out of scope

- Unexported error types (`pagesHeldError`, `contextError`): covered by
  `TestPagesHeldErrorIsTransparent` and `TestContextError`.
- Error types of the nested modules and sub-packages.
- Message wording changes other than fixes for defects the table exposes.

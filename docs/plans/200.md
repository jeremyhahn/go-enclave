# Plan: nvidia-blackwell backend (#200)

Design: [docs/backends/nvidia-blackwell.md](../backends/nvidia-blackwell.md).
Where its open questions leave a choice, the plan takes the recommended
option: a composing backend (Q1) given its CPU TEE backend as a constructor
argument (Q2), rank `inner.Rank() + 1` (Q3), CMW evidence with the GPU nonce
`SHA-256(nonce)` (Q4), go-nvml (Q5), Blackwell only with single-GPU first (Q6),
the conformance harness in `test/integration` (Q7).

## Objective

A nested module `backends/nvblackwell` (its own go.mod, requiring a released
go-enclave and golang.org/x/sys, never required by the root; nothing
registers at import) that composes a CPU TEE backend with the GPUs' evidence
and readiness gate, and refuses with typed errors on every host without the
hardware.

## Slices

1. **Module, typed errors, probe, refusal path** (this slice).
   - `errors.go`: the "Failure modes" errors (`NVMLError`, `ConfComputeError`,
     `GPUArchitectureError`, `GPUAttestationError`), plus `PlatformError` for
     non-linux builds and `DriverError` for the NVIDIA kernel driver's procfs
     entry (both match an unavailable sentinel).
   - `Probe(ctx)`: the GPU-side host check; on linux it reads the open kernel
     module's `/proc/driver/nvidia/version` and parses it; off linux it is a
     `PlatformError`.
   - `New(inner)`: refuses an `inner` that is not `Importer`, `Attester`,
     `Prober` and a confining `Confiner` with `*enclave.CapabilityError`,
     then runs `Probe`. `Backend`: Name, Rank, ConfinesProcess, Probe.
   - Tests: errors' text, `errors.Is`/`As` and Unwrap; the version parser on
     fixed buffers laid out as the driver writes them; Probe on a host
     without the driver returns `DriverError` naming the step and wrapping
     the errno; New refuses nil and the locked-memory backend.
   - Makefile: the module joins `BACKEND_MODULES`.
2. **NVML probe**: go-nvml at its latest release; device count, architecture,
   CC mode, DevTools, multi-GPU mode, ready state, each a typed refusal.
   Needs the module proxy to carry go-nvml.
3. **Import and Attest**: the wrapped handle (ByteAccess, Freezer, `As`),
   CMW evidence, the CMW format copied into `docs/reference/`.
4. **Conformance**: backendtest on the real part, from `test/integration`
   behind its own build tag (Q7).

## Out of scope

No simulator, emulator or mock device. No Hopper, no NVSwitch evidence, no
setting the ready state (the platform's attestation agent does that). No
code for any GOOS but linux beyond the refusing stub.

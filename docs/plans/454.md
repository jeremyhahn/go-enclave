# Plan: SPEC row build-and-release (#454)

Status: REFERENCE. Last verified: 2026-11-13.

## Objective

Hold the row's acceptance in [docs/SPEC.md](../SPEC.md): every gate is a
Makefile target that passes offline in the devcontainer with pinned,
checksum-verified tools; `make release`, `make release-candidate` and
`make release-alpha` each cut one kind of release from `main`; the tag's
workflow runs the full gate and a consumer check; commit and tag are signed.
The row is already marked shipped; this branch folds the open per-item PRs
and finishes the six folded items, each with the test that proves it.

## Slices, in order

Each slice merges one or more PR heads with `git merge --no-ff` (never a
cherry-pick or squash), resolves conflicts keeping both sides' intent, and
runs `make lint-gates` (build/ci/buildgates) plus the unit tests of any
package it touches.

1. CI runners: #316 (Docker jobs on the bigdisk-docker pool). Tests:
   the runs-on tables in `image_build_proxy_test.go`, `optee_disk_test.go`
   and `ci_tiers_test.go`.
2. CI triggers: #364 (CI and the review on ready-for-review).
3. Markdown link gate: #389, then item #339 (`markdown_links_test.go`).
4. Buildgates script tests: #396–#401, #430–#442 (fake docker/go/make
   drivers, tables and fuzz targets for each script).
5. Devcontainer and integration guard: #419, #443, then item #344 (unit
   tests for the guard's refusals); #424, then item #350 (shell tests for
   `run-integration-tests.sh` and a strict coverage floor).
6. Gate script shell tests: #423, then item #349.
7. Consumer check: #418, then item #343 (build providertest from the
   published module).
8. Fuzz: #425, then item #351 (`make fuzz` runs every fuzz target for a
   bounded time).
9. Close-out: docs/SPEC.md and docs/build-and-release.md agree with the
   code; changelog fragment for any caller-visible change.

## Out of scope

- New gates beyond the folded items.
- Hardware backends and their CI fixtures.
- Release tags: this branch cuts none.

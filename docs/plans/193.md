# Plan: intel-sgx backend (#193)

Design: [docs/backends/intel-sgx.md](../backends/intel-sgx.md). Where its
open questions leave a choice, the build takes the recommended option and
names it in a code comment.

## Objective

A nested module `backends/intelsgx` (laid out like `backends/armtrustzone`:
its own go.mod, depends on go-enclave and golang.org/x/sys, never the
reverse, no cgo, nothing registers at import) that runs inside a Gramine SGX
enclave and reaches SGX only through `/dev/attestation` (Q2, Q3).

## Slices

1. **Module, typed errors, probe, refusal path** (this slice).
   - `errors.go`: `ErrSGXUnavailable` / `*SGXEnclaveError{Op, Cause}` and
     `ErrSGXQuote` / `*SGXQuoteError{Op, Cause}` as "Failure modes" lists.
   - `probe.go` (linux/amd64): the Q5 probe: `attestation_type` must read
     `dcap`, the enclave's own `report` must not carry DEBUG, one quote over
     a fresh random nonce must be a version 3 ECDSA quote carrying it.
   - Report and quote parsers over the documented byte layouts.
   - Stub for every other GOOS/GOARCH: constructor and probe return the
     typed unavailable error.
   - `backend.go`: `New` runs the probe; `Name` `intel-sgx`, `Rank` 2 (Q4),
     `ConfinesProcess` true.
   - Tests: on a host without SGX, `Probe` and `New` refuse with
     `ErrSGXUnavailable` naming the `attestation_type` step; parser tests on
     fixed buffers laid out per the SGX report and DCAP quote v3 structures;
     error text, `Is` and `Unwrap`; the stub's refusal (cross builds).
   - Makefile `BACKEND_MODULES` gains the module (unit tests, lint, tidy,
     vuln scan, cross builds).
2. **Attester**: `Attest(ctx, nonce)` on the backend (Q6, recommended
   option: the quote alone, format `sgx-quote`).
   - `attest.go`: a nonce of 0 or over 64 bytes is `ErrInvalidNonce` before
     any request; the nonce is zero-padded to 64 bytes; the backend's lock
     (a `sync.Mutex` field) serialises its calls; `Evidence{Format:
     "sgx-quote", Data: quote}`.
   - `attest_linux_amd64.go`: `attestation_type` must read `dcap`
     (`*SGXEnclaveError` otherwise), then `quoteOver` and `checkQuote`, so a
     quote without the padded `REPORT_DATA` is `ErrReportDataMismatch`.
   - `attest_other.go`: the stub's `*SGXEnclaveError{Op: "platform"}`.
   - Tests: nonce lengths 0 and 65; padding of 1, 32 and 64 byte nonces;
     `checkQuote` over a padded nonce; on a host without SGX `Attest`
     refuses with `ErrSGXUnavailable` naming `attestation_type`, from many
     goroutines at once; the stub's refusal (cross builds).
3. **Importer, Sweeper, Freezer handles** over `enclave.NewMemory` (Q7).
4. **In-hardware conformance**: `backendtest` with `VerifyEvidence` (Q9)
   under Gramine on SGX hardware with FLC and DCAP (Q10), a tagged test and
   its integration target.

## Out of scope

- A simulator, emulator or mock device tree (owner ruling): without the
  hardware the slices prove the refusal path only.
- Sealing keys, `Deriver`, `RootUnsealer` (Q8).
- Out-of-tree packaging (Q1 recommends its own repository; the build starts
  as a nested module like armtrustzone, which keeps the root interface-only).
- SPEC and ROADMAP row moves (protected paths, coordinator's).
